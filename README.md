# AI Brief Bot

## Description
This repository contains the AI Brief Bot, a Python application designed to generate concise summaries and briefs based on user input.

## Installation
To install the required dependencies, please run:
```
pip install -r requirements.txt
```

## Usage
To run the application, execute:
```
python main.py
```
